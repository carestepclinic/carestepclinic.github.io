- 마취 모니터링은 PC에서 그래프 왼쪽·입력 오른쪽, 좁은 화면에서 그래프 다음 입력 순으로 배치한다. 시각·소요시간·기록 동작의 중복 여백을 줄인다.
- 투약 대기는 모니터링 아래에 배치한다. 준비 약물을 실제 투약으로 전환하는 처리에는 변경이 없다.
